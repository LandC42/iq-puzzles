# CLAUDE.md — сайт «Головоломки на закономерность»

Публичный статический сайт с визуальными головоломками (сейчас 60 задач) для GitHub Pages.
Репозиторий открытый: в него не должно попадать ничего личного (почта, пути компьютера, токены, исходные PDF).

## Структура
- `build.py` — единственный источник правды. Генерирует `img/NN_task.svg`, `img/NN_solution.svg` (800×600) и `index.html`.
  Картинки и `index.html` руками не правим — меняем `build.py` и пересобираем.
- `assets/app.js` — просмотр задачи крупно (`<dialog>`, ← →, свайп, ссылка `#N`), кнопки «Решено»,
  фильтр «Все / Нерешённые / Решённые», баннер согласия на cookie.
- `assets/style.css` — оформление: светлая и тёмная тема, адаптив до 320 px, без «неона».
- Исходные описания задач — PDF-файлы в папке; они в `.gitignore` и не публикуются.

## Как добавить задачи
1. Прочитать новый PDF (текст там часто кривыми — рендерить страницы через PyMuPDF и смотреть картинками).
2. Для каждой задачи написать функцию `taskNN()` в `build.py` по образцу соседних:
   `Card(n, условие)` → `card.body`, при необходимости `card.add_options([...])` → `card.render()` для задачи
   и `card.render("Ответ: …", буква)` для решения → `save(n, task, sol)` → `return` строки ответа.
3. Ответ обязательно проверять в коде через `assert` (симуляция, перебор, пересчёт) — так принято во всех задачах.
4. Расширить `range` в `TASKS = {...}` и запустить `python3 build.py` (полная сборка обновляет `index.html`).
5. Посмотреть каждую новую картинку (рендер SVG → PNG через Playwright/Chrome) и убрать наложения:
   варианты ответа стоят на y = 410, подписи A–F под ними, пояснение решения — внизу (1–2 строки).
6. Сравнить ответы со сводной таблицей в PDF.

Сборка детерминированная: при обходе множеств сортировать, иначе SVG меняются от запуска к запуску.

## Проверка сайта перед коммитом
- Поднять сервер `python3 -m http.server <порт> --bind 127.0.0.1` в этой папке (порт 8765 может быть занят — брать другой).
- Прогнать Playwright в Chromium и WebKit на ширине 1280 и 375: нет ошибок в консоли, битых картинок,
  горизонтальной прокрутки; работают просмотр, фильтр, «Решено», баннер и сохранение после перезагрузки.
  Предупреждения CSP о стилях в WebKit появляются только от скриншотов Playwright — это не ошибка сайта.

## Безопасность и приватность
- Строгая CSP в `index.html` (`default-src 'none'`, всё только с `'self'`): никаких inline-скриптов/стилей,
  внешних CDN, шрифтов, аналитики. Не добавлять `innerHTML` — только `textContent`.
- Cookie: `iqp_consent` (yes/no) и `iqp_solved` (номера через дефис) — только после согласия,
  Path = папка сайта, SameSite=Lax, Secure по HTTPS. Значения из cookie валидируются.
- Перед коммитом: `git add -A -n` и поиск по добавляемым файлам на почту, пути `/Users/`, токены.
- Коммиты от анонимного адреса GitHub `…@users.noreply.github.com` (настроен локально в репозитории).

## Коммиты
Коммит и пуш в `main` — только когда пользователь просит. GitHub Pages публикует ветку `main` из корня.
