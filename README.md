# Головоломки на закономерность

Визуальные головоломки на поиск закономерности: у каждой есть картинка с условием и картинка с решением и объяснением.
Сайт статический: HTML, CSS, немного JavaScript и SVG-картинки. Внешних библиотек, шрифтов, счётчиков и cookie нет.

## Как устроено

| Путь | Что это |
|---|---|
| `index.html` | главная страница (генерируется скриптом) |
| `assets/style.css`, `assets/app.js` | оформление и просмотр задачи крупно |
| `img/NN_task.svg`, `img/NN_solution.svg` | картинки задач и решений |
| `build.py` | генератор всех картинок и `index.html` |

## Пересборка

Нужен Python 3 и Pillow (`pip install pillow`; используется только для измерения ширины текста).

```sh
python3 build.py        # все задачи + index.html
python3 build.py 7 12   # только выбранные задачи (index.html не трогается)
```

Скрипт сам проверяет ответы (уникальность шифров, число областей круга Мозера, углы стрелок и т. д.) и
остановится с ошибкой, если что-то не сходится.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
Через минуту сайт будет доступен по адресу `https://<имя-пользователя>.github.io/<репозиторий>/`.
