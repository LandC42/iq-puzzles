# Головоломки на закономерность

Визуальные головоломки на поиск закономерности: у каждой есть картинка с условием и картинка с решением и объяснением.
Сайт статический: HTML, CSS, немного JavaScript и SVG-картинки. Внешних библиотек, шрифтов и счётчиков нет.

Можно отмечать задачи решёнными и показывать все, только решённые или только нерешённые.
Отметки хранятся в cookie на устройстве посетителя, и только если он согласился в баннере.

## Как устроено

| Путь | Что это |
|---|---|
| `index.html` | главная страница (генерируется скриптом) |
| `assets/style.css`, `assets/app.js` | оформление, просмотр задачи крупно, отметки «Решено», фильтр, cookie |
| `img/NN_task.svg`, `img/NN_solution.svg` | картинки задач и решений |
| `build.py` | генератор всех картинок и `index.html` |

## Пересборка

Нужен Python 3 и Pillow (`pip install pillow`; используется только для измерения ширины текста).

```sh
python3 build.py        # все задачи + index.html
python3 build.py 7 12   # только выбранные задачи (index.html не трогается)
```

Скрипт сам проверяет ответы (уникальность шифров, число областей круга Мозера, симуляции, перебор и т. д.) и
остановится с ошибкой, если что-то не сходится.

## Cookie

| Имя | Значение | Срок |
|---|---|---|
| `iqp_consent` | `yes` или `no` — ответ в баннере | 1 год |
| `iqp_solved` | номера решённых задач через дефис, например `3-7-12` (только при согласии) | 1 год |

Cookie ставятся только на путь сайта, с `SameSite=Lax` и `Secure` по HTTPS, и никуда не отправляются.
Изменить выбор можно ссылкой «Настройки cookie» внизу страницы.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
Через минуту сайт будет доступен по адресу `https://<имя-пользователя>.github.io/<репозиторий>/`.
